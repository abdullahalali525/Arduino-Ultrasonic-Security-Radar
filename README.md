 Key Features & Specifications
Proximity Range Detection: Configurable detection radius monitoring objects entering the active zone.

Dual-State Visual Indicators:

Green LED: System active and clear (no objects detected within range).

Red LED: Object detected within the active threshold.

Auditory Alert System: Integrated passive buzzer that sounds continuous alerts while an object remains in range.

Dynamic Hardware Movement: Utilizes a micro servo motor to sweep the ultrasonic sensor across the monitoring field.

Hardware Components Used:
Microcontroller: Arduino Board (e.g., Uno / Elegoo)
Sensor: HC-SR04 Ultrasonic Distance Sensor
Actuator: Micro Servo Motor (for sensor sweeping/positioning)
Output Devices: Passive Buzzer, Green LED, Red LED
Support: Breadboard, jumper wires, current-limiting resistors

Result: The System was able to run perfectly, sucessfuly rotating 180 degrees, and detected objects with exact measurements presented on the diagnostic map several times through testing. The sensor was able to identify the range and work coherently with the LED's and passive buzzer to make up a complete system where the detection range causes the red LED's to flicker and the passive buzzer to make sound as a response to the specified warning
